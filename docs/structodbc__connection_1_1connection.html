connection
Connection

Definition

Represents a database connection with ODBC, managing environment, connection, and statement handles, and providing methods to open connections, execute SQL statements, and manage transactions, with support for resultset objects.

Constructor interface for creating a new connection object with a specified ODBC connection string.

Returns
The constructed connection object.

Remarks

Parameters
[in]connstringThe ODBC connection string.
Returns
A new connection object.
